Adoption notes

The current editor combines light global shadcn tokens with explicit dark surfaces. The sidebar shell is still light and unclipped; slider tints and primitive focus/hover colors inherit the light foundation. These differences are documented, not silently repaired.

Only namespaced variables are added. Import tokens deliberately when migrating a component. Do not treat preset colors as a brand palette.
